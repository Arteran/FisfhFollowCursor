# Fish Follow Cursor

> Інтерактивний веб-додаток, де об'єкти реагують на рух курсору миші. Побудовано з використанням сучасних інструментів для забезпечення найкращої продуктивності, плавної анімації та 3D-графіки.

---

## Технологічний стек

> ### [![Vite](https://img.shields.io/badge/vite-%23646CFF.svg?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)
> **Швидка збірка проєкту**  
> *Забезпечує локальне середовище розробки та збирає всі ресурси проєкту. Завдяки HMR дозволяє миттєво бачити зміни в коді під час створення сцени.*
> ### [![Three.js](https://img.shields.io/badge/threejs-black?style=for-the-badge&logo=three.js&logoColor=white)](https://threejs.org/)
> **Рендеринг 3D-сцени**  
> *Відповідає за створення 3D-простору у браузері, завантаження та відображення моделі рибки, а також налаштування камери й освітлення сцени.*
> ### [![GSAP](https://img.shields.io/badge/GSAP-88CE02?style=for-the-badge&logo=greensock&logoColor=white)](https://gsap.com/)
> **Плавна анімація руху**  
> *Використовується для анімації переміщення та обертання рибки. Додає ефект інерції (easing), завдяки чому рибка слідує за курсором природно та плавно.*

---

## Запуск проєкту
Щоб розгорнути проєкт локально, виконайте ці команди у вашому терміналі:

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка проєкту для продакшену
npm run build
```
