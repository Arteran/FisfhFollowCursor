# Fish Follow Cursor

> Інтерактивний веб-додаток, де об'єкти реагують на рух курсору миші. Побудовано з використанням сучасних інструментів для забезпечення найкращої продуктивності, плавної анімації та 3D-графіки.

---

## Технологічний стек

<br/>

> ### [Vite](https://vitejs.dev/)
> **Інструмент для збірки та розробки**  
> *Використовується для миттєвого запуску сервера розробки та надшвидкої збірки проєкту. Забезпечує миттєвий HMR (Hot Module Replacement).*
<br/>

> ### [Three.js](https://threejs.org/)
> **3D-бібліотека для браузера**  
> *Серце візуальної частини проєкту. Дозволяє рендерити та управляти складними 3D-об'єктами за допомогою WebGL з високим FPS.*
<br/>

> ### [GSAP](https://gsap.com/)
> **Професійна анімація**  
> *GreenSock Animation Platform відповідає за плавні, високопродуктивні анімації руху, створюючи кінематографічний ефект взаємодії.*

<br/>

---

## Запуск проєкту

Щоб розгорнути проєкт локально, виконайте ці команди у вашому терміналі:

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка проєкту для продакшену
npm run build
```
